# Tokmon UI assets

This directory archives the visual assets associated with the Tokmon UI Figma
Make file `TERbwZUU7J6mBkjCh0ErTx`.

- `branding/`: Tokmon identity artwork.
- `icons/lucide/`: the exact Lucide glyph set imported by the Figma Make source.
- `reference/screens/`: full-size 1672 x 941 design reference screens.
- `reference/fragments/`: additional visual fragments bundled with the Make file.

`tokmon-brand-2048.png` remains at the asset root because the packaging target
installs that historical path. The categorized copy in `branding/` is the
canonical design archive.
